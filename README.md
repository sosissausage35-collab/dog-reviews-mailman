A one-line dog review of the mailman for make.fun's "The Dog Reviews the Mailman" bounty: one star, because every morning he sneaks up, shoves bills through the dog's door, and sprints off like he stole something — so the dog barks first, guards the gate, and lets his tail do the talking.

## Run

```bash
node main.ts
```

This prints the review line, its character count (175 / 200), and writes it to `/output/entry.txt`.
